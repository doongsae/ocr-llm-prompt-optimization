The contract comparison covers the original instruction, input/output fields,
settings, normalization, manifest rows, each scope's train and validation order,
biased train sampling, factual metric records, Boolean trace admission, and
adapter messages on controlled examples. The unit suite mocks API responses and
exercises native GEPA/Bootstrap handoff, parsing, provenance, failure handling,
and publication/archiving utilities.

`tools/verify_workflow.py` uses three synthetic train/validation examples and
bounded native optimizers with deterministic mocked SDK responses. Both source
versions produced the same requests (initial prompt: 3; GEPA: 21; Bootstrap: 23),
programs, candidate selection records, validation CSVs, and token accounting.
Runtime seconds and timestamps are deliberately excluded from equivalence.
This is an offline regression check, not a paid reproduction of the benchmark.
The checks were rerun after consolidating the training/optimizer and CLI/check
files and removing unused data helpers. They do not imply that the removed
cross-fingerprint compatibility behavior is preserved; that removal is
intentional and tested as strict rejection.

Historical analysis independently reclassified 26,826 stored final test rows:

and 62/6/22 cell wins/ties/losses versus raw OCR. No output row was generated by

## Rechecking

```bash
python -m unittest discover -s pipeline/tests -v
python tools/check_publication.py
```

To check the complete frozen-data integration, first set `OCR_DATA_MANIFEST` to
the original private manifest. Use `tools/verify_snapshot.py --original ...
--manifest ...` to compare the original completed experiment directory with
this copied pipeline. Use `tools/verify_workflow.py --original ...` for the
mocked optimizer workflow comparison. These checks do not need an API key.

## Limits

Passing offline checks does not establish bit-identical future LLM generations,
independent test generalization, absence of OCR pretraining overlap, dataset
redistribution permission, or full end-to-end OCR environment reproducibility.
The initial snapshot predated Git initialization. The first upload's actual
Git index passed inspection; rerun `python tools/check_publication.py --staged`
before each upload. Local `config.json` is rejected if accidentally staged,
and the published config template must have an empty API key.
Credential pattern checks do not replace manual review. License decisions and
upstream attribution review remain necessary before public redistribution.
